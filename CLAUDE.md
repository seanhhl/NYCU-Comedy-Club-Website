## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Language Preferences
- Whenever the user mentions "Mandarin" or "Chinese", always assume **Traditional Chinese**, never Simplified Chinese. Furthermore, always use natural Taiwanese phrasing (zh-TW) for translations.

## UI / UX Design Principles
- **Avoid Repeated Section Formulas**: Do not use the same label + headline + paragraph stack repeatedly. Vary hierarchy with full-width proof points, narrative breaks, or direct headlines.
- **Avoid Zigzag Monotony**: Do not stack three or more consecutive left/right image-text splits.
- **No Decorative Trust Theater**: Never include fabricated metrics, fake testimonials, or placeholder company logos just to fill space.
- **Thoughtful Hero Sections**: Avoid the statistical default (centered headline + gradient + two CTAs) unless explicitly requested. Design for the content.
- **Refined Interactivity (Motion Intensity)**: Default to subtle hover/focus states and short entry transitions (fade-ins, slide-ups). Avoid heavy, cinematic transitions unless appropriate for spatial storytelling.
- **Avoid AI Visual Clichés**: Do not use purple-pink gradients, excessive emojis, or left-border accent cards unless specifically required by a brand spec.
